# 일본어 뉘앙스 단어장

일본어 단어 2,043개의 뉘앙스 설명, 예문, 자주 쓰는 표현, 헷갈리는 단어를 정리한 단어장입니다.

**보기:** https://koregaseigi.github.io/jp-study/

## 기능

- 공부 중 / 외운 단어 탭 — 단어 왼쪽 ✓ 를 누르면 외운 단어로 옮겨집니다
- 단어·읽기·뜻·뉘앙스 검색
- 읽기 가리기 / 뜻 가리기 (셀프 테스트)
- 50단어 단위 페이지, 랜덤 순서 (다시 섞기 전까지 유지)
- 헷갈리는 단어는 해당 단어 항목으로 바로 이동
- 진도(외운 단어, 섞인 순서, 마지막으로 본 단어)는 브라우저 localStorage에 저장 — 로그인 없이 동작하지만 기기 간 동기화는 되지 않습니다

## 구성

- `index.html` — 단어장 전체 (프레임워크 없는 단일 HTML)
- `words.json` — 단어 데이터
